This project contains a photo album website with several sections and galleries.

## Folder Structure

- **hompage.css**: Main homepage styles
- **index.html**: Main homepage HTML
- **style.css**: General styles
- **pic 1/**, **pic 12/**, **pic Albom/**, **pic child/**, **pic family/**, **pic newborn/**: Each contains a section of the site with its own HTML and CSS
- **picSite/**: Main gallery folder
    - **p (1)** to **p (12)**: Folders for 12 images or galleries

## Gallery Folders

The `picSite` directory contains 12 folders named `p (1)` through `p (12)`. Each folder is intended to hold an image or a set of images for the gallery.

## How to Use

1. Add your images to the corresponding `picSite/p (n)` folder (where `n` is 1 to 12).
2. Reference these images in your HTML as needed.
